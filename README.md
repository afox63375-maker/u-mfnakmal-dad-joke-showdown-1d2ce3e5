# "Fully Booked" — Dad Joke Showdown Entry

> I asked my calendar for a day off, but it said it was fully booked.

## Why this joke works as a dad joke

- **Setup:** A perfectly ordinary request — asking your calendar for a day off — delivered deadpan, like a dad asking for time off work.
- **Pun:** "Fully booked" does double duty: a calendar is literally full of bookings, and "booked" is the word you use when a schedule has no room left. The joke turns a scheduling word back on itself.
- **Payoff:** The calendar answers back, straight-faced, as if it were the boss. No explanation, no wink — just the groan. It lands in one line and is short enough (67 characters) to stay well under the 200-character limit, which also helps on the byte tie-break.

## How to run

```bash
python3 main.py
```

This validates the joke (one line, 1–200 characters, UTF-8) and writes it byte-for-byte, with no trailing newline, to `/output/entry.txt`.
